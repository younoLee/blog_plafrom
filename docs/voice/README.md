# voice — 사람 글/UI 참고 자료 두는 곳

내일 작업(글투·UI에서 AI 티 줄이기)에 쓸 참고 자료를 여기 넣는다.

## samples/ — 사람이 쓴 글
- 확장자: `.md` 또는 `.txt` (docx는 텍스트로 풀어서)
- 파일 하나 = 글 하나. 이름은 `01-누구-무슨글.md` 식으로.
- 5~10편이면 충분하다. 전문이 아니어도 되고, 마음에 드는 문단만 잘라 넣어도 된다.
- 첫 줄에 `> 출처: <URL 또는 책 제목>` 한 줄만 적어두면 나중에 찾기 쉽다.
- **커밋되지 않는다**(.gitignore). 남의 글 원문이라 저장소에 올리지 않는다.

## ui-refs/ — UI 참고
- 스크린샷 이미지, 또는 `links.md`에 URL 목록.
- "이 사이트 이 부분이 좋다" 한 줄씩만 붙여도 된다. 역시 커밋 안 됨.

## 산출물
여기 자료를 읽고 뽑아낸 규칙은 `docs/voice/style-guide.md`로 정리한다.
이 파일만 커밋된다(내 문장으로 다시 쓴 규칙이라 원문이 안 남는다).

## 내일 할 일 (2026-08-19 예정)

두 갈래다.

1. **글투**: samples/의 사람 글을 읽고 → 지금 발행된 글과 뭐가 다른지 뽑아내고 →
   `style-guide.md`로 정리 → 그 규칙으로 앞으로 쓴다.
   (이미 발행된 32편은 소급하지 않는다. em dash 건과 같은 원칙.)
2. **UI**: 네이버 블로그 / 다음 블로그 같은 "한국 블로그" 느낌으로.
   ui-refs/에 스크린샷 3~5장이면 충분하다. 목록 화면 1장, 글 화면 1장,
   사이드바/프로필 1장 — 이 세 개가 제일 많이 갈린다.

UI 쪽 주의: 네이버/다음을 픽셀로 베끼는 게 목적이 아니라 **거기서 쓰는 관습**을
가져오는 것이다(썸네일 붙은 목록, 프로필 카드, 카테고리 트리, 촘촘한 본문 여백 등).
로고·서체·색 조합을 그대로 옮기면 그건 다른 문제가 된다.

### UI 방향 확정 (08-18)
velog식 카드 그리드 + 네이버식 좌측 사이드바를 **섞는다**.

- 좌측 사이드바: 프로필 카드 → 카테고리 트리(글 개수 표시) → 태그 목록
- 우측 본문: 상단에 최신/인기/태그 탭, 아래에 썸네일 카드 그리드
  (썸네일 → 제목 → 요약 2줄 → 날짜·댓글수)
- 참고 스크린샷: `ui-refs/` (velog 트렌딩 화면)
