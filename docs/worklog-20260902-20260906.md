## 관통 주제 — 닷새가 같은 곳을 가리켰다

### 1. 만들어 둔 장치가 자기 일을 하는지 아무도 안 물었다

닷새 동안 나온 것 중 가장 비싼 것들이 전부 이 모양이었다. **없어서 못 잡은 게 아니라,
있는데 안 보고 있었다.**

| 장치 | 실제 상태 | 언제 드러났나 |
|---|---|---|
| 감시 5-B(스냅샷) | 권한이 없어 **11회 연속 실패**, 아무도 안 봄 | 09-04 |
| 커널 변경 검사 | 만들어진 뒤 **한 번도 판정한 적 없음** | 09-06 |
| SSH 키 에스크로 | 고쳐놓고 **한 번도 안 돌림**(사본이 이 PC 하나) | 09-06 |
| 비상 스위치 | 세 갈래 중 **하나에서만** 동작 | 09-05 |
| `alembic check` | 기본값 차이를 안 보는 설정인데 주석은 본다고 적음 | 09-05 |
| 게임데이 스냅샷 | 지우는 절차가 없어 **엿새** 생존(비암호화, pgdata+키 21개) | 09-02 |

셋은 실패하는 방식이 조용했고(경고가 종료코드에 안 들어감), 셋은 시험이나 문서가
"돌고 있다"고 말해 주고 있었다.

### 2. 문서에 박은 값이 실물보다 먼저 낡는다

이건 닷새에 **네 번** 나왔고, 그중 둘은 같은 런북의 다른 절이었다.

- `docs/invite-signup-deploy.md` 4절 — 마이그레이션 head 가 2026-07 배포 값(`e5434ac`)
- 같은 문서 7-1 — 번들 파일명이 2026-08-07 배포 해시(`63b4a5c`)
- `watch.yml` — "매시 감시"가 실측과 다름(`2e45888`)
- 설명 자료 — 커밋 수가 허용치 30에 **29까지** 벌어져 있었다(`63b4a5c`)

7-1이 특히 나빴다. 문서대로 따라가면 **없는 파일을 받아 grep 0** 이 나오고,
그건 배포가 멀쩡한데 실패로 읽는다는 뜻이다. 그래서 넷 다 같은 방식으로 고쳤다 —
**값을 박지 않고 그때그때 읽는다**(`alembic heads`, 라이브 HTML에서 번들명 추출).

### 3. 고친 날과 그것이 실제로 판정한 날은 다르다

커널 검사는 09-06 아침에 고쳤지만 **판정하는 것을 본 것은 그날 밤 서버를 끌 때**였다.
에스크로도 09-02에 고쳐놓고 09-06에야 처음 돌았다. 서버를 켜는 회차가 와야 실증되는
장치들이라, 고친 시점에 "고쳤다"로 닫으면 이 저장소가 여러 번 이름 붙인
"고쳤다와 동작한다는 다르다"를 그대로 다시 밟는다.

  받는 쪽은 실려온 값을 읽고도 버렸다. **두 달 동안 아무도 안 보는 숫자를 올리고 있었다.**
- **결제 승인이 HTTP 200만 보고 결제 상태를 안 읽었다**(`b3933ba`). 돈 경로다.
- 종료 보호·AMI 고정·오리진 연결 1초(`b923808`) — 전부 in-place, 비용 0.

  조회 실패는 0건과 구분한다.

### 09-06 (일) — 서버 회차 하나로 남은 것을 다 닫았다

**코드**

- SEC-01 잔여를 닫았다(`d2e826e`). chunked 갈래가 본문을 `list[dict]` 가 아니라
  `SpooledTemporaryFile(512KB)` 로 받는다. 헤더를 위조해도 메모리에 남는 몫이
  6MB → 512KB다. 조각 경계는 256개까지만 재현하고 그 위로는 합친다 — 1바이트 조각으로
  6MB를 보내면 **경계 목록이 본문보다 커지는** 새 함정이 생기기 때문이고, 그것도 시험으로 박았다.
- 커널 변경 검사를 판정하게 고쳤다(`4820cf7`). 패키지 이름이 아니라 `/boot/vmlinuz-<릴리스>`
  에서 읽는다.
- 런북 4절의 마이그레이션 head(`e5434ac`), 7-1의 번들 파일명(`63b4a5c`).

**서버 회차** (2-A 대조 → 켜기 → 배포 → 4절 → 4-B → 5절 → 프론트 → 7-1 → 에스크로 → 정지)

- **커널 검사가 처음으로 판정했다** — 정지 로그에 `OK 커널 변경 없음`.
- **SSH 키 에스크로가 처음 돌았다** — `check` 네 줄 전부 초록.
- 프론트 4커밋 배포. 번들 이름만 보지 않고 **이번 변경의 고유 문자열**로 확인했다.
