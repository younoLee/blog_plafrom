# 소개

안녕하세요. **younoLee**입니다. 이 블로그를 직접 만들고, 만드는 과정을 그대로 적고 있습니다.

## 이 블로그는 무엇인가

글을 올리려고 만든 블로그가 아니라, **만드는 과정을 기록하려고 만든 블로그**입니다.
그래서 여기 있는 글의 대부분은 이 사이트 자신에 대한 이야기입니다 —
무엇을 만들었고, 무엇이 고장 났고, 고쳤다고 생각한 것이 실제로는 안 고쳐져 있었다는 이야기.

연재 「블로그 만들기」가 그 기록입니다. 30편이 넘고, 전부 그날 실제로 있었던 일만 적었습니다.
잘된 것보다 **틀린 판단과 그걸 알게 된 경위**를 더 많이 적었습니다. 그게 나중에 더 쓸모 있었기 때문입니다.

## 어떻게 만들었나

- **백엔드** — Python · FastAPI · SQLAlchemy · Alembic · PostgreSQL
- **프론트** — React · TypeScript · Vite · Tailwind CSS
- **인프라** — AWS EC2 · S3 · CloudFront · WAF · SNS · CloudTrail · Terraform
- **운영** — Docker Compose · GitHub Actions(CI/CD) · pytest · Vitest · ruff · mypy

몇 가지는 흔한 선택이 아닙니다. 이유가 있습니다.

- **서버는 평소 꺼져 있습니다.** 개인 블로그에 상시 과금할 이유가 없어서, 필요할 때만 켭니다.
  그래서 글 목록과 개발일지 아카이브는 서버 없이도 열리는 정적 페이지로 따로 만들어 둡니다.
  화면이 "서버가 절전 중"이라고 안내하면 고장이 아니라 설계입니다.
- **가입은 초대제입니다.** 봇 가입을 막을 장치를 제대로 만들 생각이 없어서, 아예 닫았습니다.
  계정은 초대 링크로만 생깁니다.
- **인프라는 전부 코드로 관리합니다.** 콘솔에서 손으로 바꾼 것이 남아 있으면
  재해 복구 때 그 자리에서 헤매게 됩니다. 실제로 그걸로 한 번 크게 데었고, 그 이야기도 연재에 있습니다.
